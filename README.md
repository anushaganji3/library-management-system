# 📚 Library Management System (Python)

## 📌 Description
A simple console-based Library Management System built using Python.  
It allows users to perform basic library operations such as adding books, viewing available books, issuing books, and returning them.

---

## ⚙️ Features
- ➕ Add new books
- 📖 View all books
- 📤 Issue books
- 📥 Return books
- 💾 Data stored using JSON file

---

## 🧑‍💻 Tech Stack
- Python
- File Handling (JSON)

---

## ▶️ How to Run
1. Make sure Python is installed  
2. Clone the repository or download the files  
3. Open terminal in project folder  
4. Run the program:  

```bash
python library.py
